## 注意
1. 本素材是用于课堂路演的AI概念效果图，不是实际生产或已实现功能的证明。
2. 商品造型仅包括Cloud长绒云朵、Sun短绒太阳、Star硅胶星星，不包括兔子。
3. ¥399为核心主机+任选五行人格之一+任选一个外壳+底座+充电线+挂包配件；额外外壳¥59。
4. 独立站里应以真实HTML按钮覆盖图片上绘制的按钮，不要把静态图片上的按钮当成可点击控件。
5. 部分图片来自生成的总览板裁切，分辨率较低，适合课堂Demo的卡片；高精度商品主图可在此基础上继续单独生成。
